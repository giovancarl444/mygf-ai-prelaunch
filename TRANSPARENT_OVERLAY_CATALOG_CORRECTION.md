# Transparent Overlay Catalog Correction

## User-Corrected Card Rule

The World Library companion card is now a **single 3:4 portrait tile**. A transparent dark gradient rises from the lower portion of each frame to make compact white text legible. The card itself contains the adult-age metadata, companion name, and concise world tag, rather than rendering a colored dossier underneath the portrait.

## Visual Acceptance Finding

The final 1280px desktop review shows four fixed portrait cards across with a predictable scanning rhythm. Names are clearly separated in white, category and adult-age information is visible but secondary, and the low-contrast gradient preserves portrait detail while protecting legibility. CSS-only abstract world previews use the same geometry and white overlay typography, keeping the long list visually consistent.

## Deliberate Originality Boundaries

The implementation uses MyGF.ai’s own violet-black environment, world taxonomy, fictional adult identities, search/filter semantics, and copy. It does not use another product’s name, logo, CTA wording, character concepts, badges, or subscription language. The earlier “zero overlay” requirement has been superseded by the user’s explicit instruction to use a transparent text overlay; the card therefore uses no separate colored metadata box beneath the portrait.
